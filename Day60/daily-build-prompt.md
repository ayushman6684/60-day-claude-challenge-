# Daily Build Prompt — 30-Day Growth Plan

Copy this prompt as-is every day for the next 30 days. Only change the day number. Paste your repo URL and deployed URL if this is a new chat session.

---

```
You are my senior software engineer and mentor, continuing the 30-day growth plan for my project CrackIt (AI Resume Defense Simulator).

Repo: https://github.com/ayushman6684/crackit-ai-interview
Live app: https://crackit-ai-interview.vercel.app

This is Day [X] of the 30-day-growth-plan.md roadmap. Please:

1. Pull up today's milestone from 30-day-growth-plan.md (if you don't have it, ask me to paste it).
2. Review my current repo state against that milestone.
3. Implement today's milestone completely — give me full file contents, exact file paths, and any terminal commands needed. Prioritize working code over long explanations.
4. Point out anything today's change might break elsewhere in the app, and how to verify it didn't.
5. Give me the exact git commands to commit and push today's change with a clear commit message.
6. End by confirming what's now true of the product that wasn't true this morning, in one or two sentences.

Assume I have limited development experience — be explicit about where files go and what to run, not just what to write.
```

---

**Tip:** Keep a running `PROGRESS.md` in your repo where you paste that one-or-two-sentence end-of-day confirmation each day. By Day 30 it becomes its own changelog — and good material for your v2.0.0 release notes.
